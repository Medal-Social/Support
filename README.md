# Medal Social Support

Downloads for **Medal Social Support**, the remote help app for Medal Social customers.

Get the app from **https://app.medalsocial.com/support/app**, or from the latest release on this page:

- macOS (Apple silicon): `MedalSocialSupport-macos-arm64.dmg`
- Windows (64-bit): `MedalSocialSupport-windows-x64-install.exe`
- Android: [Google Play](https://play.google.com/store/apps/details?id=com.medalsocial.support)

The app only connects to Medal Social's own servers, and a support session can only start after you have linked the device to your business in Medal Social and a Medal Social staff member starts it from your workspace. Nothing is recorded.

Medal Social Support is based on [RustDesk](https://github.com/rustdesk/rustdesk) (AGPL-3.0). Source code is available on request: support@medalsocial.com
